# Blocky Smash City

A blocky 3D ragdoll sandbox game that runs in your web browser.

**▶ Play it here:** https://aussiescupper.github.io/blocky-smash-city/

> ⚠️ Contains cartoon blood and gore.

## Features
- Floppy ragdoll physics with broken bones, wounds and a live health/skeleton panel
- Weapons: fists, gun, knife, sword, bat, burgers, grab, chainsaw, axe, hammer, flamethrower, rocket launcher and a medkit
- 🧪 **Pool Lab** game mode with 12 pools: milk, acid, lava, honey, gravy, slime, water, ice, oil, soda, chocolate and electric
- Avatar editor, gore upgrade shop, teleport and spawn menus

## Controls
- **WASD** move · **Shift** run · **Space** jump
- **Click** the game to look around with the mouse (Esc to get the mouse back)
- **1–0, -, =, K** pick a tool · **Click** to use it
- **R** ragdoll · **F** first person · **B** shop · **T** teleport · **G** spawn · **M** menu
