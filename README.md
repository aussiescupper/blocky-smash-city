# Blocky Smash City

A blocky 3D ragdoll sandbox game that runs in your web browser.

**▶ Play it here:** https://aussiescupper.github.io/blocky-smash-city/

> ⚠️ Contains cartoon blood and gore.

## Features
- Floppy ragdoll physics with broken bones, wounds and a live health/skeleton panel
- 17 tools: fists, gun, knife, sword, bat, burgers, grab, chainsaw, axe, hammer, flamethrower, rocket launcher, medkit, shotgun, grenade, freeze ray and laser sword
- 🧪 **Pool Lab** game mode with 20 pools: milk, acid, lava, honey, gravy, slime, water, ice, oil, soda, chocolate, electric, piranhas, nitrogen, gold, blood, shark, helium, paint and a black hole
- NPCs that fight back (some with guns), bullet holes, bleeding and drowning, plus a little body display that shows broken and lost limbs
- 📱 Works on iPad: joystick on the left, swipe on the right to look, big buttons to use and jump
- Avatar editor with 5 body types (normal, muscular, skinny, big, short), gore upgrade shop, teleport and spawn menus

## Controls
- **WASD** move · **Shift** run · **Space** jump
- **Click** the game to look around with the mouse (Esc to get the mouse back)
- **1–0, -, =, K, Z, X, N, V** pick a tool · **Click** to use it
- **R** ragdoll · **F** first person · **B** shop · **T** teleport · **G** spawn · **M** menu
